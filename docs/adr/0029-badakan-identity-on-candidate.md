# App-validated Candidates copy Badakan identity files and numbers onto the fiche

Recruiters need the full Badakan dossier on the Candidate (CV, CNI, RIB, diploma, NIR, IBAN), not a round-trip to the app admin. CV stays `cvUrl`; other files are Documents on the Candidate. These fields are not matching criteria and are not shown in Intérim availability filters. Leaving pieces only in Badakan was rejected.
