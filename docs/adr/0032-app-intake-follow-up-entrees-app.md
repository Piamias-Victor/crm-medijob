# App intake follow-up (« Entrées app ») replaces Profils app; no Hireflix, no ACCEPTE

The Syncro sheet cockpit becomes Intérim **App intake follow-up** at `/interim/entrees-app` (UI « Entrées app ») — a table-only list of AppProfiles not yet App-validated, with inline Intake status, Call outcome, RDV date, notes, Referent, and relance. It **replaces** the Candidats « Profils app » tab and AppProfile detail/convert pages. **Hireflix invitation is removed**; the existing Intake booking SMS (Google Calendar) stays untouched. **Recruiter ACCEPTE is removed** — the only success door into the CVthèque is Badakan App-validated (CRM remains read-only toward Badakan). Negative Call outcomes / `Hors zone` / **Ignore** leave the default view like App-validated, and stay findable via an archived filter. Keeping a parallel Profils app inbox or a manual ACCEPTE path was rejected: one file, one exit rule, no dual saisie with the sheet.
