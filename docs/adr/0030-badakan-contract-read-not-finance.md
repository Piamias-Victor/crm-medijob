# Badakan contracts are an Intérim read list, not Finance

V1 reads Badakan contracts (status, PDF, DPAE) into the Intérim module, in schema and on a list — same treatment as Badakan missions. They are not Lignes de suivi, not Devis, and the CRM does not write contracts to Badakan. Schema-only with no UI was rejected (dead data). Leaving them out of V1 was rejected: it would reopen the read model later.
