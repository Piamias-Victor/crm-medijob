# Facturation follow-up uses an October–September Exercice

A calendar year (January–December) would not match Medijob steering or the op-medijob figures (cumulative CA, 240 k€ CDD/CDI cap, monthly table Oct→Sep).

Decision: Facturation Pilotage, Placements, and Intérim filter by **Exercice** (1 October – 30 September). Rejected: calendar year; rejected: making start/end dates an admin setting for V1.
